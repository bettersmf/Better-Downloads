# Better Downloads

**A clean, integrated downloads manager for SMF 2.1.x.**

Better Downloads adds a dedicated downloads area to Simple Machines Forum with categories, release files, screenshots, publishing controls, member-group submission permissions, and deep integration with the Better SMF ecosystem.

> **Keep SMF familiar. Make it better.**

## Features

- Dedicated downloads manager for SMF 2.1.x
- Download categories
- Add and edit downloadable items
- File uploads and release management
- Multiple screenshots per download
- Download counts and item details
- Member-group submission controls
- Admin publishing and management workflow
- Clean SMF-style administration interface
- Better Portal integration
- Better Tags integration
- Interactive Downloads Browser support for Better Portal
- Latest Downloads and Most Downloaded portal blocks
- Uninstall behavior designed to preserve data unless explicitly purged

## Installation

1. Download the latest Better Downloads package from the GitHub **Releases** section.
2. In SMF, open **Administration Center → Main → Package Manager → Download Packages**.
3. Upload the Better Downloads ZIP.
4. Install the package normally.
5. Open **Administration Center → Configuration → Better Downloads** to configure categories, downloads and settings.

## Better SMF Integrations

### Better Portal

Better Downloads can provide Latest Downloads, Most Downloaded, and an interactive Downloads Browser for portal pages.

### Better Tags

When Better Tags is installed and its Downloads integration is enabled, downloads can participate in the shared Better SMF tag system alongside forum topics and Better Gallery content.

## Administration

The Better Downloads admin area includes dedicated sections for:

- Downloads
- Add/Edit Download
- Categories
- Add/Edit Category
- Settings

The admin layout follows the SMF visual language: the outer panel owns the complete border while the category header and content body live inside it as one unified cell.

## Project Structure

The install package contains the SMF source file, template, stylesheet, language file, admin/menu icons, install/uninstall handlers and `package-info.xml`.
